
# Satta Result Website

A mobile-friendly result chart website built using HTML, CSS and JavaScript.

## Features

- Responsive mobile layout
- Result table with date columns
- Market names and result numbers
- Record Chart links
- Refresh button
- Disclaimer with Read More option

## Technology

- HTML5
- CSS3
- JavaScript

## Setup

Open `index.html` in a browser.

## GitHub Pages Deployment

1. Open repository Settings.
2. Select Pages.
3. Choose Deploy from a branch.
4. Select `main`.
5. Select `/(root)`.
6. Click Save.

## Important

This is a static demonstration website. Results are sample data and are not connected to a live data source.
